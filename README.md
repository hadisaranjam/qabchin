# قاب‌چین وب — نسخهٔ ۲۷

وب‌اپ فارسی صفحه‌آرایی کمیک، بر پایهٔ قاب‌چین نسخهٔ ۲۶.

## استفاده

- ویرایش راست‌به‌چپ، ۱۴ چیدمان، قاب آزاد، تصویر، خروجی PNG چاپی و PDF.
- کتابخانهٔ چندکتابی با ذخیرهٔ خودکار روی دستگاه، ورود فایل پروژه و کپی کتاب.
- نصب روی موبایل و رایانه؛ پس از اولین بارگیری کامل، کار آفلاین.
- سینک شخصی کتاب‌ها **همراه تصویرها** در مخزن خصوصی `hadisaranjam/qabchin-private-data`.
- ارسال فقط تصویرهای تازه، تشخیص تغییر هم‌زمان دو دستگاه، نگهداری هر دو نسخه در تداخل.
- نام کتاب و صفحهٔ فعال نیز ذخیره می‌شوند.

## اتصال سینک

در کتابخانه، «اتصال سینک» را بزنید. لینک ساخت کلید محدود همان‌جا وجود دارد.

۱. یک **fine-grained personal access token** در GitHub بسازید.
۲. در Repository access، **Only select repositories** و فقط **qabchin-private-data** را انتخاب کنید.
۳. مجوز **Contents: Read and write** را بدهید. دسترسی گسترده، سازمانی یا مدیریتی نیاز نیست.
۴. کلید را فقط داخل فرم اتصال برنامه وارد کنید؛ نه در چت، کد، URL یا فایل پروژه.
۵. در دستگاه شخصی، نگهداری رمز‌شده اختیاری است. کلید با AES-GCM و کلید مشتق‌شده از رمز محلی (PBKDF2، ۳۱۰ هزار دور) ذخیره می‌شود. با بستن صفحه، کلید بازشده از حافظه می‌رود و برای بازکردن اتصال باید رمز را وارد کنید.

روی دستگاه دیگر همین نشانی برنامه را باز کنید، اتصال را برقرار کنید و کتاب ابری را بگیرید. هر دستگاه می‌تواند کلید محدود خودش را داشته باشد. کلید منقضی‌شده را از «فراموش‌کردن اتصال» جایگزین کنید.

کار محلی بدون اتصال هم قابل استفاده است. پس از ورود، سینک خودکار حدود ۲۰ ثانیه بعد از توقف ویرایش انجام می‌شود؛ تغییر ابری هر دقیقه و هنگام برگشت به صفحه بررسی می‌شود. پیش از جابه‌جایی دستگاه بهتر است «سینک اکنون» و پیام موفقیت را ببینید. هنگام بسته‌بودن برنامه، سینک پس‌زمینه انجام نمی‌شود.

## حریم خصوصی و حدود

سایت و کد برنامه عمومی‌اند؛ پروژه‌ها، تصاویر و کلیدها داخل مخزن سایت نیستند. سینک به مخزن عمومی رد می‌شود. هیچ سرویس تحلیل یا CDN در اجرا استفاده نمی‌شود. فقط پس از اتصال کاربر، درخواست‌های سینک مستقیماً به `api.github.com` می‌روند. پاسخ‌های خصوصی در Service Worker کش نمی‌شوند.

تصویرها در مخزن خصوصی بدون رمزگذاری سرتاسری ذخیره می‌شوند؛ هر کسی که به آن مخزن دسترسی داشته باشد می‌تواند آن‌ها و تاریخچهٔ نسخه‌ها را بخواند. رمز محلی فقط از کلید ذخیره‌شده در مرورگر محافظت می‌کند. پاک‌کردن دادهٔ مرورگر، کتاب‌های محلی و اتصال ذخیره‌شده را پاک می‌کند؛ فایل پشتیبان JSON مستقل نگه دارید.

این نسخه برای استفادهٔ شخصی است، نه همکاری هم‌زمان. تصویر سینک‌شونده حداکثر ۳۰ مگابایت و متادیتای هر کتاب حداکثر ۹۰۰ کیلوبایت است. تاریخچهٔ GitHub تصاویر قبلی را نگه می‌دارد؛ برای آرشیوهای بسیار بزرگ، فضای ذخیره‌سازی رسانه‌ای اختصاصی مناسب‌تر است. محدودیت سرویس رایگان و دسترسی شبکه به GitHub همچنان برقرار است.

## توسعه و انتشار

```sh
npm ci
npm run build
npm test
npm start
```

`site/` خروجی قابل انتشار است. `source/src` موتور اصلی ویرایشگر است؛ `web/` کتابخانه، سینک، رمزگذاری اتصال و PWA را اضافه می‌کند. خروجی تک‌فایلی آفلاین در `single-file/` قابلیت سینک وب را ندارد.

با هر push به main، GitHub Actions آزمون‌های منطق و مرورگر را اجرا می‌کند و فقط در صورت موفقیت، سایت را روی GitHub Pages منتشر می‌کند. ساخت کلید شخصی و ورود آن در هر دستگاه به عهدهٔ صاحب حساب است و در کد یا فرایند انتشار خودکار انجام نمی‌شود.

## آزمون

```sh
npm test
npx playwright install chromium
npm run test:e2e
```

آزمون‌ها شامل هندسهٔ ویرایشگر، خروجی PDF/PNG، کتابخانهٔ محلی، هم‌زمانی دو زبانه، رمزگذاری کلید، سینک دو دستگاه، حفظ تصاویر، تداخل نسخه‌ها، رد مخزن عمومی، بارگیری آفلاین و اندازه‌های موبایل/تبلت/رایانه‌اند. آزمون مرورگر از GitHub ساختگی استفاده می‌کند و اطلاعات واقعی کاربر نمی‌فرستد.

## فونت
